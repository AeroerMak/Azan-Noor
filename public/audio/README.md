# Azan Audio Files

Place your Azan `.mp3` recordings here. The app looks for:

| File | Muezzin |
|------|---------|
| `azan-alafasy.mp3`  | Mishary Rashid Alafasy |
| `azan-makkah.mp3`   | Masjid al-Haram (Makkah) |
| `azan-madinah.mp3`  | Masjid an-Nabawi (Madinah) |
| `azan-sudais.mp3`   | Sheikh Abdurrahman Sudais |

## Free sources

- https://www.islamcan.com/audio/adhan/
- https://github.com/islamic-apps/azan-audio
- https://download.islamway.net/

All recordings used must be free for non-commercial use.
